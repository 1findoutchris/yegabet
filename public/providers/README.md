Provider logos for the lobby's provider tiles.

Name each file after the provider's slug — the part after /casino/ in the
provider page URL (e.g. `pragmatic-play.svg` for /casino/pragmatic-play).
SVG preferred; PNG or WebP also work. Use the provider's official logo,
light-coloured or white so it reads on the dark tiles. Without a file the tile
shows the provider name as text.
